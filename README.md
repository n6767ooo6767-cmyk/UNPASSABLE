# UNPASSABLE

A deliberately ridiculous password game. Enter a password and survive 100+ increasingly absurd rules.

## Play
Open `index.html` in a browser, or enable GitHub Pages for the repository.

## Features
- 100+ rule definitions
- Rules unlock as the password grows
- All unlocked rules must remain satisfied
- Live validation
- No backend required
- Designed to be extended with more rules

## Note
Some rules are intentionally contradictory. That's part of the challenge: the game is meant to become increasingly absurd and require experimentation.
